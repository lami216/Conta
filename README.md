# Conta POS

نظام عربي بسيط لنقطة البيع وإدارة المخزون لمتجر يعمل بموقعين:

- المخزن الرئيسي الذي يستقبل الحاويات وشحنات الموردين.
- البوتيك الذي يستقبل التحويلات أو المشتريات المباشرة من السوق ويبيع للزبائن.

العملة هي **MRU** ولا تُحسب TVA. البيع النقدي هو الافتراضي، مع دعم بنكيلي، مصرفي، السداد، بيم بنك، والبيع بالدَّين لزبون مسجّل.

## المرحلة الحالية

هذه أول مرحلة تشغيلية للواجهة وتغطي:

- نقطة بيع عربية RTL قابلة للاستخدام باللمس ولوحة المفاتيح.
- الفرد والكرتون مع تحويل تلقائي عند بلوغ حجم الكرتون.
- استلام البضاعة إلى المخزن أو البوتيك مباشرة.
- تحويل المخزون من المخزن إلى البوتيك.
- البيع النقدي والإلكتروني والبيع بالدَّين.
- تسجيل سداد الزبون وتحديث رصيده.
- عرض المخزون والحركات والتقارير اليومية الأولية.

البيانات المعروضة حاليًا تجريبية داخل الواجهة حتى تكتمل طبقة MongoDB Atlas في المرحلة التالية. لا تُستخدم بيانات المتصفح كمصدر دائم للحقيقة.

## التشغيل المحلي

المتطلبات:

- Node.js 22.13 أو أحدث.

```bash
npm ci
npm run dev
```

## قواعد العمل المثبتة

- كل كمية مخزون تُخزّن بوحدة **الفرد**، ويُشتق منها عدد الكراتين والباقي.
- سعر الكرتون مستقل؛ وإن لم يُدخل يُحسب من سعر الفرد وحجم الكرتون.
- التحويل الداخلي لا يُسجل كمبيعة أو ربح.
- البيع بالدَّين لا يكتمل إلا بعد اختيار زبون مسجّل.
- المنتجات لا تستخدم تواريخ صلاحية أو أرقام دفعات.
- المالك هو المستخدم التشغيلي ولا توجد موافقات إدارية على الخصومات أو العمليات.

تفاصيل تصميم MongoDB والمعاملات موجودة في [docs/architecture.md](docs/architecture.md).

## الأسرار

لا تضع رابط MongoDB أو كلمات المرور أو مفاتيح النشر داخل المستودع. تُحفظ في متغيرات البيئة أو GitHub Secrets فقط.

## فحوص الجودة

```bash
npm run lint
```

تم فحص المسارات الأساسية تفاعليًا: بيع نقدي، بيع بالدَّين، استلام مباشر للبوتيك، تحويل من المخزن، وسداد دين.
