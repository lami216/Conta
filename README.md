# Conta POS

نظام عربي فعلي لنقطة البيع والمشتريات والمخازن وحسابات الأطراف والمصاريف. مصدر الحقيقة هو Cloudflare D1، ولا تعتمد العمليات على بيانات تجريبية داخل المتصفح.

## الوظائف

- فاتورة بيع ببحث قبل إظهار المنتجات، وتسعير مستقل للفرد أو الكرتون داخل كل فاتورة.
- وسائل الدفع المباشر تسدد الفاتورة كاملة، والبيع المؤجل يظهر باسم «ملاحظة» ويرتبط بطرف موحد.
- فواتير شراء متعددة المنتجات إلى أي مخزن مسجل.
- طرف واحد يعمل تلقائيًا كعميل ومورد، مع سداد وتسوية ومقاصة قابلة للتتبع.
- مخازن غير محدودة، ومخزن بيع افتراضي قابل للتغيير، وتحويل ثنائي القيد بين أي مخزنين.
- تصحيح مخزون جماعي يسجل الرصيد قبل الجرد وبعده والفرق.
- إرجاع جزئي من فاتورة البيع دون تعديل أو حذف أصل الفاتورة.
- مصروفات لمرة واحدة أو يومية أو شهرية، مع مفتاح استحقاق يمنع الاحتساب المكرر.
- كل حركة مالية أو مخزنية تنتج مستندًا قابلًا للفتح والطباعة والتنزيل.

## التشغيل

```bash
npm run install:ci
npm run dev
```

طبّق `db/schema.sql` على قاعدة D1 قبل أول تشغيل. الربط اسمه `DB` كما هو محدد في `.openai/hosting.json`.

## التحقق

```bash
npx tsc --noEmit
npm run lint
npm test
```

اختبار التكامل ينفذ دورة كاملة: طرف موحد، منتجات، شراء إلى مخزن محدد، تحويل، بيع نقدي، ملاحظة، مصاريف متكررة، إرجاع جزئي، تصحيح، سداد، مقاصة، مخالصة، وفحص إمكانية تتبع كل حركة إلى مستندها.
