# البنية المحاسبية والمخزنية

## مصدر الحقيقة

تستخدم Conta قاعدة Cloudflare D1. الواجهة تقرأ لقطة تشغيلية من `/api/bootstrap` وترسل أوامر فقط إلى `/api/command`. الخادم يعيد حساب الإجماليات، يتحقق من الرصيد، ثم يطبق الكتابات المرتبطة عبر `D1.batch` كوحدة ذرّية.

## الكيانات

| الكيان               | الغرض                                                     |
| -------------------- | --------------------------------------------------------- |
| `parties`            | طرف موحد يعمل كعميل ومورد دون ربط يدوي                    |
| `warehouses`         | أي عدد من المخازن، مع مخزن بيع افتراضي واحد               |
| `products`           | المنتج وأسعار الفرد والكرتون، دون تصنيفات                 |
| `documents`          | أصل كل بيع وشراء وإرجاع وتحويل وتصحيح ومصروف وسداد ومقاصة |
| `document_lines`     | المنتجات والكميات والأسعار المجمدة وقت العملية            |
| `stock_balances`     | الرصيد الحالي المشتق لكل منتج داخل كل مخزن                |
| `stock_movements`    | أثر مخزني غير قابل للحذف مع الرصيد قبل وبعد               |
| `ledger_entries`     | أرصدة القبض والدفع للطرف الموحد                           |
| `allocations`        | ربط السداد أو المخالصة بالفواتير التي سوّاها              |
| `recurring_expenses` | تعريف المصروف اليومي أو الشهري                            |
| `audit_events`       | مسار تدقيق إضافي للأوامر المنشورة                         |

## قواعد العمليات

- الشراء يزيد المخزن المحدد، وينشئ التزامًا للمورد فقط إذا كان مستحقًا.
- البيع يخصم مخزن البيع المحدد ويمنع الرصيد السالب. وسائل الدفع المباشر لا تنشئ ذمة، والملاحظة تنشئ مبلغًا مستحقًا على الطرف.
- التحويل ينقص المصدر ويزيد الوجهة داخل الدفعة نفسها، مع حركتي خروج ودخول مرتبطتين بمستند واحد.
- التصحيح لا يستبدل الرقم بصمت؛ يسجل الرصيد السابق والفعلي والفرق.
- الإرجاع يتحقق من الكمية الأصلية والمرتجع السابق، يزيد المخزون، ويعكس الذمة عند وجودها.
- المقاصة تنقص رصيد القبض ورصيد الدفع بالقيمة نفسها دون المساس بالفواتير الأصلية.
- `recurrence_key` فريد لكل استحقاق يومي أو شهري، لذلك لا ينتج عن إعادة الطلب فاتورتان للفترة نفسها.
- المحفوظات المعتمدة وحركات المخزون وقيود الطرف محمية من الحذف بواسطة Triggers.

## الأرقام

القيم المالية تخزن كأعداد صحيحة بوحدة MRU. كميات المخزون تخزن بالأفراد فقط، ويشتق عرض الكراتين من `pieces_per_carton`. جميع مدخلات الأرقام في الواجهة LTR ويمكن تركها فارغة أثناء التحرير.
